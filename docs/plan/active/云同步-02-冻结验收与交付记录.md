## 最终修订

本轮以总计划的来源归属规则补充永久 `ever_published` 及签名证明字段，修复“已发布来源取消后继就被释放”的漏洞。proof 先于清库/fence 生成时，新 runtime 使用经过验签的更高 fence recovery bundle；已有账号库仍不得跨过未确认 Outbox。crypto-destroy 的 hash 仅为可信私有 journal 查找键，必须认证并匹配全部绑定，缺 key/缺数据库不构成允许释放的证明。

保密设备缓存选用 account/workspace-scoped Keystore AEAD，普通索引只含状态。诊断输出是精确白名单，文件使用 900 秒固定 TTL 与 boot-bound elapsed time；系统分享完成、过期或 boot 不可信均清理。实际 FileProvider 和产品生命周期 owner 属于 05，02冻结格式、顺序、权限和失败路径。
