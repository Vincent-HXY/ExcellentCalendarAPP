# ADR-0004: Anniversary 使用独立实体

Status: Accepted
Date: 2026-08-10

## Context

当前 Event 同时承担普通事件、提醒和纪念日语义。

纪念日具有：
- 每年重复
- 年数计算
- 特殊展示
- 独立提醒策略

如果继续塞入 Event，会增加大量 nullable 字段和条件分支。

## Decision

Anniversary 建模为独立 Domain Entity。

Flutter / Kotlin / JNI / C++ 使用独立 anniversary contract。

## Alternatives

### A. Event 增加 anniversaryType

优点：
- 实现改动较少

缺点：
- Event 模型膨胀
- 大量字段只对 Anniversary 有效

### B. Anniversary 独立实体

优点：
- 领域语义清晰
- Contract 独立
- 后续扩展容易

缺点：
- 增加接口数量

## Consequences

Positive:
- Event 模型保持简单
- Anniversary 生命周期可以独立演进

Negative:
- JNI API 增加
- Repository 需要支持第二类实体

## Revisit When

如果以后统一成通用 recurrence domain model，
重新评估 Event / Anniversary 的继承关系。
