# Offline display fonts

Derived from Google Fonts Noto Sans SC and Noto Serif SC variable fonts (SIL Open Font License 1.1). Copyright and licenses are retained in the adjacent OFL files and registered in Flutter's license registry. No runtime download is performed.

- https://github.com/google/fonts/tree/main/ofl/notosanssc
- https://github.com/google/fonts/tree/main/ofl/notoserifsc

Downloaded 2026-09-05. Subset with fontTools 4.64.0: retain GB2312 characters, U+0020–00FF, U+2000–206F, U+3000–303F and U+FF00–FFEF; retain all names, languages, layout features and variable weight axes. Family/name records substitute `Calendar` for `Noto` to distinguish these modified files. Missing glyphs fall back to the platform font. The application exposes the familiar descriptions “思源黑体（常用字）” and “思源宋体（常用字）”.
