# Application Layer

负责编排用户业务流程，是 UI 和底层能力之间的业务协调层。

## 具体任务

- 创建、修改、删除日程时编排默认提醒、分类、重复规则、通知注册和同步日志。
- AI 导入后组织候选日程确认流程。
- 生成今日任务：今日习惯、今日日程、近期准备任务。
- 处理习惯打卡后的统计刷新。
- 处理用户开启或关闭云同步后的同步策略。
- 协调搜索、筛选、四象限、日历聚合等功能调用。

## 交付标准

- 不写 UI 组件。
- 不直接访问 SQLite。
- 调用 Gateway Interfaces 或 Core Engine 暴露的接口。
- 每个业务流程应有明确输入、输出和失败处理。
