# Presentation Layer

负责所有页面、组件和用户交互展示。

## 具体任务

- 实现日程创建/编辑/详情页面，包含时间、标题、详情、提醒、地点、重要性、响铃、微信提醒、重复规则和分类。
- 实现日历视图：年、月、周、最近三日。
- 实现今日任务主页：习惯坚持、日程安排、准备任务。
- 实现习惯、搜索、四象限、纪念日、个人信息、投送消息等界面。
- 展示 loading、空状态、错误提示、确认弹窗和 AI 候选日程确认界面。

## 交付标准

- 页面只表达UI状态，不负责处理任何决定核心业务规则。
- 所有用户操作通过 Application Layer 或 State Management 触发。
- 组件应可复用，复杂页面拆分为清晰的小组件。
