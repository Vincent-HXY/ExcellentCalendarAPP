# ADR-0001：采用模块化单体

- 状态：Accepted
- 日期：2026-08-01

## 决策

第一阶段使用一个 Java 21 / Spring Boot 代码库和一个数据库，通过业务包与 Spring Modulith 测试
约束模块边界，不拆微服务。

## 原因

账号、资料、同步、提醒、通知和媒体仍在共同演进。模块化单体保留强事务与低运维成本，同时让未来
可以按稳定边界抽出通知、AI 或媒体服务。

## 后果

- 跨模块只能使用公开 Application API 或明确事件；
- 禁止共享或直连其他模块的 JPA Entity/Repository；
- 模块独立扩缩容之前，先用 API/Worker/Scheduler 运行角色隔离负载；
- 只有出现明确扩缩容、故障隔离、团队所有权或合规需求时才评估拆分。
